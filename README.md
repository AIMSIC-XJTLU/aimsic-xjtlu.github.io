# AIMS Research Group at XJTLU

[Group website](https://aimsic-xjtlu.github.io/)

The site consists of static English-language pages. Open `index.html` to preview it locally.

- Edit the top-level HTML files to update About, Research, Projects, Members, News or Contact.
- The project directory and publication list are in `projects.html`. Circuit project pages are in `projects/`, and the NS-RAM overview is in `ns-ram.html`.
- Member names, SURF cohorts, alumni destinations and gallery captions are in `people.html`. News entries are in `news.html`.
- Images, styles, fonts and navigation scripts are in `assets/`. The page headers and footers are present in each content page.
- For a change to the set of pages, update `sitemap.xml`. Keep `.nojekyll` for branch-based static deployment and `aims/index.html` for older bookmarks.
